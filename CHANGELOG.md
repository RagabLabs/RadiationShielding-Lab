# Changelog

## 1.0.0 — 2026-10-14

- Independent React/TypeScript photon attenuation application; 15 views and 10
  explicitly related scientific calculations.
- Two traceable NIST dataset families; original response snapshots, SHA256
  provenance, material compositions and reference densities.
- Segmented log-log lookup with both absorption-edge limits and no extrapolation.
- Monoenergetic and discrete polyenergetic uncollided attenuation through layers.
- Stable log transmission, expm1 attenuation fractions and log-space spectral sums.
- English/Arabic navigation and content, RTL, dark/light themes, responsive CSS.
- Eight kinds of scientific SVG chart; pointer/keyboard inspection and PNG export.
- Shared analysis snapshot for CSV and English PDF exports.
- Independent Decimal references, Vitest scientific/data/DOM/report tests,
  a built-bundle DOM smoke check and prepared desktop/mobile Playwright suites.
- Production assets and a self-contained file-openable START-HERE.html.
- CI and a separate, manually approved GitHub Pages publication workflow.

Browser-engine validation is not represented as completed; see the actual test
report and remaining limitations.
